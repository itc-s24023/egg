# AIごっち 企画書

## 企画の目的

会話や遊びなどの世話を通じて、プレイヤーがAIキャラクターの性格、口調、好きな話題を自分好みに育てられるゲームを提供する。AIとの日常的なコミュニケーションと育成ゲームの楽しさを組み合わせ、継続して遊びたくなる体験を実現する。

## 企画の概要

「AIごっち」は、ユーザーとの会話や世話の内容に応じてAIキャラクターが変化・成長する育成ゲームである。Gemini APIを利用したAIチャットを中心に、ごはん、遊ぶ、寝かせるなどの世話、ステータス確認、会話履歴、ミニゲームを提供する。

Webブラウザで利用でき、Vercel上に公開する。開発期間は2026年10月1日から2026年12月20日までを予定する。

## ターゲット

- AIとの日常会話を楽しみたい人
- 育成ゲームやキャラクターとの交流が好きな人
- 自分だけのキャラクターを育てたい人
- 会話を重ねながらキャラクターの変化を楽しみたい人

## 企画の詳細

- メールアドレスとパスワードによるユーザー登録・ログイン
- AIキャラクターとのチャット
- 話しかける、ごはん、遊ぶ、寝かせるなどのお世話
- お世話によって経験値を獲得し、成長段階を「たまご」「こども」「せいちょう」の3段階で変化
- 会話やお世話の内容に応じた性格、口調、好きな話題の変化
- おなか、元気、なかよし度などのステータス表示
- キャラクターの話題・性格分析の表示
- 過去の会話履歴の確認
- じゃんけん、〇✕ゲーム、オセロ、五目並べなどのミニゲーム
- 設定画面からのキャラクター詳細確認、育成のやり直し、ログアウト
- パスワード再設定
- 利用規約の提示
- キャラクターが死亡した場合の育成データ初期化確認と、育てた日数・性格タイプの表示

## 環境・技術要件

- **開発環境**
  - Webブラウザで動作するアプリケーション
  - Vercelへのデプロイ
  - 開発期間：2026年10月1日〜2026年12月20日
- **使用するプログラミング言語やフレームワーク**
  - JavaScriptまたはTypeScript
  - Webアプリケーション用フレームワーク
  - Gemini APIを利用したAIチャット・キャラクター分析
- **データベースや外部サービス**
  - ユーザー情報、キャラクターの育成状態、ステータス、会話履歴、ゲーム結果を保存するデータベース
  - Gemini API
  - Vercel
  - パスワード再設定用のメール送信サービス
- **セキュリティ要件**
  - Gemini APIキーなどの認証情報はソースコードやブラウザに直接公開せず、サーバー側の環境変数で管理する
  - Vercelの環境変数を利用し、開発・プレビュー・本番環境ごとに設定を分離する
  - ユーザー認証情報と会話履歴を適切に保護する
