# AIごっち 要件定義書

|機能ID|機能名|機能概要|優先度|備考|
|---|---|---|---|---|
|F-01|ユーザー登録|メールアドレスとパスワードでアカウントを作成する|高|登録後に育成を開始できる|
|F-02|ログイン|登録済みユーザーを認証し、育成画面へ遷移する|高|認証状態を維持する|
|F-03|キャラクター育成|世話や会話に応じて経験値・成長段階・性格を変化させる|高|たまご、こども、せいちょうの3段階|
|F-04|AIチャット|AIキャラクターと会話し、会話内容を育成に反映する|高|Gemini APIを利用|
|F-05|ステータス表示|キャラクターの成長段階、満腹度、元気、なかよし度などを表示する|高|トップページと詳細画面で表示|
|F-06|会話履歴表示|ユーザーとAIキャラクターの過去の会話を一覧表示する|中|ユーザー本人の履歴のみ表示|
|F-07|設定・育成やり直し|設定確認、キャラクター情報の確認、育成データの初期化を行う|中|初期化前に確認を表示|
|F-08|ログアウト|ログイン状態を終了し、ログイン画面へ遷移する|高|セッションを破棄する|
|F-09|お世話|ごはん、遊ぶ、寝かせるなどの行動でステータスを変化させる|高|経験値も加算する|
|F-10|話題・性格分析表示|会話やお世話の傾向から、話題や性格タイプを表示する|中|育成状況に応じて更新する|
|F-11|じゃんけん|AIキャラクターとじゃんけんを行い、勝敗を表示する|中|結果を育成に反映する|
|F-12|〇✕ゲーム|AIキャラクターと〇✕ゲームを行い、勝敗を表示する|中|結果を育成に反映する|
|F-13|オセロ|AIキャラクターとオセロを行う|低|実装範囲・対戦ロジックは設計時に確定する|
|F-14|五目並べ|AIキャラクターと五目並べを行う|低|実装範囲・対戦ロジックは設計時に確定する|

## 共通要件

- Webブラウザから利用でき、Vercelへデプロイできること。
- ユーザーごとに育成データと会話履歴を分離して管理すること。
- Gemini APIキーなどの秘密情報をブラウザへ公開せず、サーバー側の環境変数で管理すること。
- 不正な入力、未認証アクセス、APIエラーが発生した場合は、ユーザーに明示的なエラーを通知すること。
- スマートフォンとPCのブラウザで主要画面を利用できること。
