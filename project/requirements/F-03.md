# キャラクター育成

## 詳細

会話やお世話によって経験値と各種ステータスを変化させ、一定の経験値に達したときに成長段階を上げる。会話傾向と行動履歴は性格、口調、好きな話題の変化に利用する。

## 仕様

- 成長段階は「たまご」「こども」「せいちょう」の3段階とする。
- 経験値150で「たまご」から「こども」、経験値300で「せいちょう」へ成長する。
- 性格タイプは「たまご」の間は「？」とし、「こども」以降に確定する。
- 会話内容に該当する性格パラメーターを変化させる。楽しい・嬉しい・元気・挑戦などの前向きな表現は明るさを10、冗談・笑い・ネタ・ゲームなどの表現はユーモアを10上げる。質問記号1つにつき論理を10（最大30）上げ、質問語を含む発言は論理を10上げる。感謝や、教えてもらった内容への肯定的な反応を含む発言は丁寧さを10上げる。孵化時に最大値のタイプを固定する。
- 経験値はAIとの会話1往復につき10、世話やミニゲームなどの対象行動に応じて加算する。
- 成長段階の変化条件とステータスへの影響は、データベース設計時に定義する。
- 育成データはユーザー単位で保存し、トップページとキャラクター詳細画面から参照できる。
- キャラクター死亡時は、育成日数と性格タイプを表示した後、育成やり直しを選択できる。
