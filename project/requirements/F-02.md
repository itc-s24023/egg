# ログイン

## 詳細

Firebase Authenticationで登録済みのメールアドレスとパスワード、またはGoogleアカウントを認証する。認証済みユーザーだけがFirestore上の育成データ、会話履歴、設定を利用できる。

## 仕様

- 入力：メールアドレスとパスワード、またはGoogleアカウント
- サーバー処理：Firebase IDトークンをFirebase Admin SDKで検証し、FirebaseセッションCookieを発行する
- 成功時：Firestoreのユーザーと初期キャラクターを確認・作成し、トップページへ遷移
- 失敗時：認証失敗を通知し、ログイン画面に留まる
- 未認証で保護画面へアクセスした場合：ログイン画面へ遷移
- Firebase Admin SDKの資格情報はサーバー環境だけに設定し、`NEXT_PUBLIC_` 変数に含めない
